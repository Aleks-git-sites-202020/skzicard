# АвтоОка — точки роста

Статическая страница с разбором гипотез роста, планом теста и таймлайнами.

## Деплой на Vercel

1. Запушить этот репозиторий на GitHub.
2. Зайти на [vercel.com](https://vercel.com), нажать **Add New → Project**.
3. Импортировать репозиторий — Vercel сам определит статический `index.html`, доп. настройки не нужны.
4. Нажать **Deploy**.

## Локальный просмотр

Просто открыть `index.html` в браузере — внешних зависимостей нет, кроме шрифтов Google Fonts.
